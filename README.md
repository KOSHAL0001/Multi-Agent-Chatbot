# 🤖 Multi-Agent Chatbot

A multi-agent AI chatbot designed to handle user queries using multiple specialized AI agents. The project demonstrates how different agents can work together to process tasks and generate intelligent responses.

## 🚀 Features

- 🤖 Multi-Agent AI Architecture
- 💬 Interactive Chatbot Interface
- 🧠 Specialized AI Agents
- 🔀 Intelligent Task Handling
- 🔐 Secure API Key Configuration using Environment Variables
- ⚡ Fast and Interactive User Experience

## 🛠️ Tech Stack

- Python
- Streamlit
- AI / LLM APIs
- Python-dotenv

## 🧠 How It Works

The chatbot follows a multi-agent workflow:

User Query  
↓  
Chatbot Interface  
↓  
Task Processing / Agent Selection  
↓  
Specialized AI Agent  
↓  
Response Generation  
↓  
Final Response to User

Different agents can be assigned different responsibilities, allowing the system to handle multiple types of tasks efficiently.
